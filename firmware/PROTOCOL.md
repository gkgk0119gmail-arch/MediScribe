# 아두이노 모터 제어 프로토콜 (펌웨어 v3)

젯슨 ↔ 아두이노 Mega 2560, USB 시리얼 115200 bps, 줄 단위 ASCII 명령.
펌웨어 소스는 이 저장소에 없다. 아래는 도움말(`?`)과 바퀴를 띄운 실험으로 확인한 동작이다.
젯슨 쪽 구현: [`medinav/hal/arduino_v3.py`](../medinav/hal/arduino_v3.py).

| 명령 | 뜻 | 실험 결과 |
|---|---|---|
| `D <pwm>` | 양쪽 뒷바퀴 같은 PWM (−255..255) | `D 150` 전진, `D -150` 후진 |
| `V <l> <r>` | 좌/우 뒷바퀴 개별 PWM (정수만, 소수는 0 으로 무시) | `V 120 0` 왼쪽만 전진 |
| `S <pwm> [ms]` | 조향 모터 펄스 (+ = 오른쪽). ms 생략 시 워치독까지 | `S 255 1000` 오른쪽 끝까지 |
| `X` | 정지 → `OK STOP` | |
| `T L\|R\|S <dir 0/1> [pwm] [ms]` | 모터 하나씩 시험 (기본 pwm 150) | |
| `C L\|R\|S 0\|1` | 방향 반전 플래그 | |
| `?` | 도움말 | |
| (수신) `ST a b c ms` | 100 ms 주기 상태. 마지막 값은 가동 시간 — 줄어들면 아두이노가 재부팅된 것(전압 강하) | |
| (수신) `WD STOP` | 명령이 약 0.5초 끊기면 스스로 멈춘다(워치독) | |

## 설계 메모

- **조향은 각도 센서가 없는 DC 모터**다. 각도를 지령할 수 없어서 펄스로 밀고, 주행 코드가
  라이다 정합으로 잰 실제 회전 속도(요레이트)를 보고 펄스를 더 줄지 정한다(`scripts/nav_drive.py`).
- **워치독**: 젯슨이 죽거나 USB 가 빠지면 0.5초 안에 멈춘다. 젯슨 쪽은 명령을 50 Hz 로 계속 다시 보낸다.
- 워치독은 "명령이 끊김"만 잡는다. 조이스틱 버튼이 눌린 채로 굳는 경우처럼 **젯슨이 잘못된 명령을
  계속 보내는 상황은 못 잡는다** → 물리 비상정지(ESC 전원 차단) 스위치를 반드시 둔다.
- 알려진 문제: 왼쪽 조향이 오른쪽보다 약하다(끝까지 못 가고 멈출 때가 있음). 기구 또는 드라이버 쪽으로 보고 있다.
